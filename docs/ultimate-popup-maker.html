Ultimate Popup Maker Documentation

Learn how to construct multi-layer 60fps popups, configure exit-intent rules, collect subscriber leads, and connect instant webhooks.

1. Overview & Architecture

Unlike legacy WordPress popup plugins that load multi-megabyte jQuery frameworks, heavy static templates, and intrusive tracking beacons, Ultimate Popup Maker was engineered with performance-first web standards:

  • < 20KB Vanilla JavaScript: Ultra-lean visitor runtime with zero jQuery dependencies.
  • 0.00ms Layout Shift: Absolute overlay hardware-accelerated stacking ensures 100/100 Core Web Vitals compliance.
  • Local CRM Storage: All captured emails and metadata are saved in dedicated, optimized WordPress custom tables without external vendor lock-in.

2. Installation & Quick Start

  1. Download your license ZIP package from your MicroPlugins account receipt.
  2. In your WordPress Admin, go to Plugins → Add New Plugin → Upload Plugin.
  3. Select ultimate-popup-maker.zip and click Install Now.
  4. Click Activate Plugin.
  5. Navigate to the new Popup Maker admin menu item to launch the canvas builder.

3. Multi-Layer Visual Canvas

Each popup in Ultimate Popup Maker is built as a composition of discrete visual layers:

Supported Layer Types:

  • Backdrop Layer: Color overlay, glassmorphism blur, or click-to-dismiss background.
  • Shell Layer: Modal container, slide-in bar, or full-viewport takeover canvas.
  • Typography & Badges: Heads, subheads, discount badges with custom angles/rotation.
  • Lead Capture Inputs: Single-field email bar, full lead generation forms, or GDPR consent checkboxes.
  • Countdown Timers: Evergreen or fixed-date urgency timers with automated action triggers.

4. 60fps Animation Sequencing

Set staggered entrance delays and transition physics using native CSS hardware acceleration (GPU transform and opacity):

Sequencer Example Timeline 
000ms: Backdrop fade-in (opacity 0 -> 1)
150ms: Modal shell spring-in (scale 0.9 -> 1.0, translateY 20px -> 0px)
300ms: Badge elastic bounce (rotate -12deg -> 0deg)
450ms: Form fields fade and slide (opacity 0 -> 1)

5. Behavioral Triggers & Targeting

Configure exactly when and to whom your popup displays:

  • Exit Intent (Desktop): Triggers when cursor velocity indicates the user is moving toward tabs or the close button.
  • Exit Intent (Mobile): Detects rapid upward scrolling velocity and browser back button navigation.
  • Scroll Depth: Trigger after scrolling past a designated page percentage (e.g. 50% or 75%).
  • User Inactivity: Fires after the visitor has been idle for N seconds.
  • Frequency Capping: Show only once per visitor per session, or wait N days between views.

6. Leads CRM & Webhooks

Every submission is stored directly inside your WordPress database under Popup Maker → Leads CRM. You can export submissions to CSV with a single click.

To automatically synchronize leads with Mailchimp, ActiveCampaign, HubSpot, or webhook routers (Zapier, Make, Pabbly):

  1. Open your popup in the editor and click Integrations → Webhook.
  2. Enter your endpoint URL (e.g., https://hooks.zapier.com/hooks/catch/...).
  3. Select the HTTP method (POST) and click Send Test Payload.

7. Blocks & Shortcode API

Insert popups or embedded lead forms into any post or page:

Shortcode Reference 
<!-- Manual Trigger or Inline Form -->
[upm_popup id="black-friday-offer"]

<!-- Trigger via button click -->
<button class="btn btn-primary" data-upm-trigger="black-friday-offer">
  Claim Your Discount
</button>

8. JavaScript Custom Events

Ultimate Popup Maker dispatches standard DOM CustomEvents for easy integration with Google Analytics 4, Meta Pixel, or custom scripts:

JavaScript Listener 
document.addEventListener('upm:popupOpen', (event) => {
  console.log('Popup opened:', event.detail.popupId);
});

document.addEventListener('upm:leadSubmit', (event) => {
  console.log('Lead captured:', event.detail.email, event.detail.popupId);
});
